02. ШІ-інструменти і вайбкодинг для мікроконтролерів

ШІ — найкращий репетитор і співавтор коду, але в embedded він працює наосліп: не бачить вашої плати і не відчуває, як гріється транзистор. Тут розібрано, які інструменти обрати і як побудувати процес, у якому ШІ отримує зворотний зв'язок від компілятора, симулятора і реального заліза.

Стан на листопад 2026Рейтинги ШІ змінюються щомісяця. Оглядові статті (daily.dev, aitoolsreview, nxcode, theairankings та інші) суперечать одна одній у цифрах бенчмарків і цінах, а частина з них є партнерським контентом. Нижче — узагальнена тенденція, застосована до нашої задачі. Ціни перевіряйте на сайтах виробників.

Чим embedded відрізняється від звичайного вайбкодингу

Код не запустиш «просто так»Потрібен ланцюжок: збірка → прошивка → залізо або симулятор. Агент, який сам запускає збірку, корисніший за чат.
ШІ не бачить платуВін не знає, що і куди ви підключили. Це треба описати текстом у файлі CLAUDE.md.
Типові помилки ШІВигадані піни, адреси I2C і регістри, плутанина версій бібліотек (наприклад, API LEDC в Arduino-ESP32 2.x і 3.x відрізняється).
Помилка може спалити залізо5 В на пін 3.3 В, MOSFET без резистора на затворі. Схему завжди перевіряє людина — з мультиметром і datasheet.

Система вайбкодингу: замкнений цикл

Головний принцип: ШІ має отримувати зворотний зв'язок — помилки компілятора, поведінку в симуляторі, лог з реальної плати. Без цього він «вгадує».

Що налаштувати один раз

  1. CLAUDE.md у корені проєкту (вже є). Агент читає його автоматично. Там: залізо, таблиця пінів, адреси I2C, обмеження (3.3 В, strapping-піни), команди збірки, правила.
  2. Datasheet-и в docs/datasheets/: PDF з сайтів виробників (AO3400, BH1750, SSD1306, VL53L0X). Кажіть агенту: «спершу прочитай datasheet».
  3. PlatformIO CLI доступний з терміналу, щоб агент міг виконати pio run (див. 03).
  4. Wokwi: diagram.json + wokwi.toml у firmware/. Для автоматичних перевірок є Wokwi CLI: wokwi-cli --timeout 10000 --expect-text "[main] ready" (потрібен токен; умови див. на wokwi.com/pricing).
  5. Git: коміт після кожного кроку, що працює. Якщо агент «наламав» — git restore ..
  6. Однаковий формат логів: [модуль] ключ=значення. Такий лог легко скопіювати агенту, і він його однозначно зрозуміє.

Шаблони запитів

Новий модуль

Додай модуль X у firmware/src. Використовуй тільки піни з config.h, без delay().
Після змін запусти `pio run -e esp32c3` і виправ усі помилки.
Поясни зміни як для C#-розробника (з аналогіями з Unity).

Налагодження

Ось лог з Serial Monitor:
[ctrl] mode=AUTO state=OFF lux=152.0 dark=0 motion=1 ...
На платі: рух є, але стрічка не вмикається, у кімнаті темно.
Спершу запропонуй 3 гіпотези і як кожну перевірити. Код поки не змінюй.

Навчання

Розбери firmware/src/Controller.cpp рядок за рядком.
Порівняй зі state machine в Unity Animator.
Потім постав мені 5 контрольних питань і перевір мої відповіді.
