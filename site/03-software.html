03. Програмне забезпечення

Що встановити на Windows, щоб писати, збирати та прошивати код для ESP32-C3 і STM32, і як перевірити, що все працює.

Необов'язково

  • Arduino IDE 2 — простіша за PlatformIO, підійде для перших 1–2 уроків.
  • ESP-IDF — «рідний» фреймворк Espressif; варто спробувати після проєкту.
  • PulseView (sigrok) — з логічним аналізатором дозволяє бачити сигнали I2C і ШІМ.

Встановлення крок за кроком

  1. Встановіть VS Code → Ctrl+Shift+X → знайдіть PlatformIO IDE → Install → перезапустіть VS Code. Перший запуск триває кілька хвилин, бо PlatformIO завантажує власний Python та інструменти.
  2. Встановіть Git.
  3. File → Open Folder → оберіть папку lessons. PlatformIO знайде platformio.ini і завантажить платформу ESP32 (це довго тільки перший раз).
  4. На нижній синій панелі: ✓ Build, → Upload, 🔌 Serial Monitor; поруч — вибір env (l01_blink, …).
  5. Щоб ШІ-агент міг запускати pio з терміналу, додайте до змінної PATH папку %USERPROFILE%\.platformio\penv\Scripts.

Перша прошивка

cd lessons
pio run -e l01_blink -t upload
pio device monitor -b 115200
Очікуваний результатСиній LED на платі мигає, у моніторі з'являються рядки [blink] led=1 count=….

Особливості ESP32-C3 Super Mini

  • USB під'єднаний прямо до чипа (USB-Serial/JTAG), окремого чипа CH340 немає. Драйвер у Windows 10/11 зазвичай не потрібен.
  • Щоб Serial працював через USB, у platformio.ini є прапор -DARDUINO_USB_CDC_ON_BOOT=1.
  • Плата не прошивається або немає COM-порту? Затисніть BOOT, натисніть RST, відпустіть BOOT, прошийте, потім натисніть RST.
  • Використовуйте кабель з лініями даних: «зарядні» кабелі не працюють.

Яку платформу ESP32 обрано

У наших platformio.ini вказано офіційну платформу platformio/espressif32. Станом на листопад 2026 вона постачає Arduino-ESP32 3.3.x і не потребує Git. Прошивку і всі уроки перевірено саме на ній. Спільнотна збірка pioarduino (новіший Arduino-ESP32) лишається закоментованою альтернативою. Код сумісний з обома (через #if ESP_ARDUINO_VERSION_MAJOR >= 3).

Особливості STM32F411 Black Pill

  • Без програматора (USB DFU): затисніть BOOT0, натисніть NRST, відпустіть BOOT0. З'явиться пристрій «STM32 BOOTLOADER». Якщо не виходить, тримайте BOOT0 довше. Іноді потрібен драйвер WinUSB (Zadig) або встановлений STM32CubeProgrammer.
  • З ST-Link V2 (рекомендовано): SWDIO, SWCLK, GND, 3V3. Дає покрокове налагодження з breakpoints.
