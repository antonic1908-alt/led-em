Wokwi — головний симулятор

wokwi.com — браузерний симулятор мікроконтролерів, а також розширення для VS Code.

Є у Wokwi підходить

  • ESP32-C3 (DevKitM-1), STM32F103 Blue Pill, Nucleo C031/L031
  • OLED SSD1306
  • PIR-датчик руху
  • фоторезисторний модуль (з повзунком lux)
  • HC-SR04 (з повзунком відстані)
  • кнопки, світлодіоди, резистори

Немає у Wokwi замінюємо

  • BH1750 → фоторезисторний модуль (аналоговий)
  • VL53L0X → HC-SR04
  • MOSFET і стрічка → світлодіод на піні ШІМ
  • STM32F411 Black Pill → для STM32-логіки є Blue Pill (F103)

Тому в прошивці є окремий env esp32c3_sim з прапором SIM_MODE=1: він бере дистанцію з HC-SR04, а світло — з аналогового входу. Прошивка навіть без прапора автоматично перемикається на аналоговий датчик, якщо не знаходить BH1750.

Запуск у VS Code

cd firmware
pio run -e esp32c3_sim
# відкрити firmware/diagram.json → F1 → "Wokwi: Start Simulator"

Запуск у браузері

  1. wokwi.com → New Project → ESP32-C3 (Arduino).
  2. Вкладка diagram.json → вставити вміст firmware/diagram.json.
  3. Додати файли з firmware/src/ (кнопка «+» біля вкладок). Вміст main.cpp вставити в sketch.ino.
  4. Library Manager → додати U8g2, BH1750, VL53L0X (від Pololu).
  5. На початку config.h дописати #define SIM_MODE 1.

Що робити в симуляції

  • Клацнути на PIR — імітація руху (сигнал тримається ~3 с).
  • Клацнути на фоторезисторі — повзунок освітленості: 10 lux = темно, 1000 lux = світло.
  • Клацнути на HC-SR04 — повзунок відстані.
  • Кнопки — мишею або клавішами 1 UP, 2 DOWN, 3 OK, 4 MANUAL.
  • Serial Monitor внизу показує лог [ctrl] ….
Якщо Wokwi лається на пінПлата у Wokwi — DevKitM-1, а не Super Mini, але чип той самий. GPIO20 у Wokwi називається RX, а GPIO21 — TX. Якщо якесь з'єднання не підхопилося, перетягніть дріт мишею в редакторі.

Ціна Wokwi

Онлайн-версія безкоштовна для особистого використання. Wokwi for VS Code: 30-денна пробна ліцензія, безкоштовно для open-source, а далі платний план. Актуальне — на wokwi.com/pricing.

Falstad CircuitJS — щоб зрозуміти електроніку

falstad.com/circuit показує анімований струм у схемі. Зберіть у ньому:

  1. Дільник напруги: 3.3 В → резистор 10k → змінний резистор (замість LDR) → GND. Крутіть повзунок і дивіться напругу в середній точці.
  2. MOSFET-ключ: 5 В → резистор 10 Ом (замість стрічки) → N-MOSFET → GND; на затвор — перемикач 0 / 3.3 В через 100 Ом, плюс 100k на GND. Подивіться, де тече струм.
  3. Pull-up: 3.3 В → 47k → вузол → кнопка → GND. Що буде у вузлі, коли кнопка відпущена і коли натиснута?
