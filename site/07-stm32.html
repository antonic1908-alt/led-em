07. Перенесення на STM32F411 (Black Pill)

ESP32 зручний і має Wi-Fi. STM32 — промисловий стандарт: побутова техніка, автомобілі, обладнання. Перенесення того самого проєкту наочно показує, що в коді залежить від заліза, а що ні.

Плата Black Pill і піни проєкту

Крок 1. Той самий код — інша плата (PlatformIO + STM32duino)

У firmware/platformio.ini уже є env blackpill:

cd firmware
pio run -e blackpill               # зібрати
pio run -e blackpill -t upload     # прошити (за замовчуванням через USB DFU)

Як прошити

  1. USB DFU: затиснути BOOT0 → натиснути NRST → відпустити BOOT0 → pio run -e blackpill -t upload. У Windows може знадобитися драйвер WinUSB (Zadig) або встановлений STM32CubeProgrammer.
  2. ST-Link V2: у platformio.ini поставити upload_protocol = stlink. З'єднання: SWDIO↔DIO, SWCLK↔CLK, GND↔GND, 3.3V↔3V3.
  3. Лог: через USB CDC (увімкнено прапорами -DUSBCON -DPIO_FRAMEWORK_ARDUINO_ENABLE_CDC).
Живлення модулівI2C-модулі і дільник живляться від 3V3 Black Pill, HC-SR501 і стрічка — від 5 В. Земля спільна.

Крок 2. «По-справжньому»: STM32CubeIDE + HAL

Мета — побачити, що Arduino-функції роблять під капотом.

  1. File → New → STM32 Project → обрати STM32F411CEUx.
  2. У файлі .ioc (CubeMX):
    • RCC: HSE = Crystal (25 МГц на Black Pill); Clock Configuration → HCLK 100 МГц.
    • SYS: Debug = Serial Wire — інакше ST-Link «загубить» плату.
    • TIM1 CH1 = PWM Generation на PA8. Prescaler = 0, Counter Period (ARR) = 4999 → 100 МГц / 5000 = 20 кГц.
    • I2C1 на PB6/PB7, Fast Mode 400 кГц.
    • ADC1 IN1 на PA1.
    • GPIO Input + Pull-up: PB12–PB15 (кнопки); GPIO Input: PB0 (PIR).
    • USB_OTG_FS Device + Middleware USB_DEVICE (CDC) — для логу.
  3. Згенерувати код. Свій код пишіть лише між /* USER CODE BEGIN */ і /* USER CODE END */, бо решту CubeMX перезапише. Скажіть про це ШІ-агенту явно.

Відповідники Arduino → HAL

Wire (BH1750)HAL_I2C_Master_Transmit / HAL_I2C_Master_Receive
analogRead(PA1)HAL_ADC_Start → HAL_ADC_PollForConversion → HAL_ADC_GetValue
/* USER CODE BEGIN 2 */
uint8_t cmd = 0x01;                                  // BH1750: Power On
HAL_I2C_Master_Transmit(&hi2c1, 0x23 << 1, &cmd, 1, 100);
cmd = 0x10;                                          // Continuous H-Resolution
HAL_I2C_Master_Transmit(&hi2c1, 0x23 << 1, &cmd, 1, 100);
HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1);
/* USER CODE END 2 */

/* USER CODE BEGIN 3 */
uint8_t buf[2];
HAL_I2C_Master_Receive(&hi2c1, 0x23 << 1, buf, 2, 100);
float lux = ((buf[0] << 8) | buf[1]) / 1.2f;          // формула з datasheet
__HAL_TIM_SET_COMPARE(&htim1, TIM_CHANNEL_1, lux < 30 ? 4000 : 0);
HAL_Delay(200);                                       // лише для демо!
/* USER CODE END 3 */
