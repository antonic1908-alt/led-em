06. Проєкт: розумна LED-стрічка

Технічне завдання, логіка роботи, меню і архітектура прошивки. Код лежить у firmware/src/; тут пояснено, як він влаштований і чому саме так.

Що вміє пристрій

  1. Керує одноколірною стрічкою 5 В через AO3400: ШІМ 20 кГц, гамма-корекція, плавне вмикання й вимикання.
  2. Режим АВТО: вмикає світло, коли спрацював датчик руху та/або дистанції і темно (або завжди — налаштовується). Після останнього спрацювання світить N секунд і плавно гасне.
  3. Режим РУЧНИЙ: датчики ігноруються, світло вмикається і вимикається лише кнопкою.
  4. Показує стан на OLED; усі параметри змінюються в меню кнопками.
  5. Зберігає налаштування у flash: ESP32 — NVS (Preferences), STM32 — EEPROM-емуляція.
  6. Раз на секунду пише лог у Serial.

Логіка режиму АВТО — скінченний автомат

Пастка зворотного зв'язкуЯкщо оцінювати «темно» постійно, то стрічка ввімкнеться, її світло потрапить на датчик, стане «світло» — і вона вимкне сама себе, потім знову ввімкнеться… Тому освітленість оцінюється лише коли стрічка вимкнена.
Аналогія з UnityЦе Animator Controller з трьома станами і умовами переходів. У коді це enum class State { Off, On, Hold } і switch (state_) в методі update(), який викликається кожен кадр.
switch (state_) {
  case State::Off:
    if (trigger_ && lightOk) state_ = State::On;
    break;
  case State::On:
    if (!trigger_) { state_ = State::Hold; holdStart_ = now; }
    break;
  case State::Hold:
    if (trigger_) state_ = State::On;
    else if (now - holdStart_ >= s_.holdSec * 1000UL) state_ = State::Off;
    break;
}

Принципи

  • Жодного delay(): кожен модуль має update(now), що повертається майже миттєво.
  • Апаратні відмінності ESP32 і STM32 сховані за #if defined(ARDUINO_ARCH_ESP32) лише в трьох місцях: піни, ШІМ, збереження.
  • Налаштування зберігаються не на кожне натискання, а при виході з меню — flash має обмежену кількість циклів запису.
  • Без BH1750 або датчика дистанції прошивка не падає: переходить на аналоговий датчик або показує «--».

Ідеї для розвитку

  • «Нічний режим»: 20 % яскравості вночі (час через Wi-Fi + NTP).

  • Кілька зон стрічки (ще один MOSFET).
  • Адресна стрічка WS2812B та ефекти (FastLED).
