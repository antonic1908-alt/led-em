01. План навчання

Від «ніколи не тримав мікроконтролер» до власного пристрою за 6–8 тижнів по 5–8 годин на тиждень. Кожен етап закінчується контрольною точкою: чимось, що можна побачити своїми очима.

Головна ідея: мікроконтролер — це Unity без рушія

Мікроконтролер — маленький комп'ютер без операційної системи. Після ввімкнення він виконує одну вашу програму, вічно. Немає вікон, файлів і збирача сміття, зате є ніжки (піни), на яких можна вмикати й вимикати напругу та вимірювати її.

Контрольна точкаВбудований синій LED мигає, а в Serial Monitor щосекунди з'являється [blink] led=1 count=….

Етап 1 — C++ для C#-розробника тижні 1–2, паралельно з уроками

Ви вже знаєте змінні, умови, цикли, класи. Нове лише таке:

  1. Типи фіксованої ширини: uint8_t (0…255), int16_t, uint32_t. На мікроконтролері пам'ять рахується в байтах.
  2. Препроцесор: #include, #define, #if. Це «текстова заміна» до компіляції, так ми обираємо код для ESP32 або STM32.
  3. Header/source: Button.h — оголошення класу (як interface), Button.cpp — реалізація.
  4. Вказівники та посилання: Settings& s — передати об'єкт без копіювання (як ref у C#).
  5. const / constexpr: константи, обчислені під час компіляції, не займають RAM.
  6. Переповнення: uint8_t x = 255; x++; → 0. Тому таймер пишемо як if (now - t0 >= interval).
  7. Неблокуючий код і скінченний автомат — головна навичка embedded-розробника.
// Неблокуюче мигання: loop() ніколи не «засинає»
uint32_t last = 0;
void loop() {
  uint32_t now = millis();
  if (now - last >= 500) {   // пройшло 500 мс?
    last = now;
    digitalWrite(8, !digitalRead(8));
  }
  // ...тут встигаємо опитати кнопки, датчики, дисплей
}
Аналогія з UnityУявіть, що в Update() ви написали Thread.Sleep(1000): гра замерзне на секунду. delay(1000) робить те саме: поки він триває, кнопки не реагують, дисплей не оновлюється.

Ресурси: learncpp.com (розділи 1–13, вибірково) і ШІ-асистент з промптом «поясни як C#-розробнику».

Етап 3 — Проєкт тижні 4–6

  1. Прочитати ТЗ (06) і зібрати схему (05).
  2. Прошити готову прошивку з firmware/ і переконатися, що все працює.
  3. Разом з ШІ розібрати кожен модуль: кнопки → датчики → драйвер стрічки → контролер → меню.
  4. Додати власну функцію, наприклад «нічний режим» на 20 % яскравості з 23:00 до 6:00 (час — через Wi-Fi/NTP).

Етап 4 — STM32 тижні 6–8

  1. Той самий проєкт на STM32F411 через PlatformIO — змінюються лише піни.
  2. STM32CubeIDE + CubeMX + HAL: тактування, таймер у режимі ШІМ, I2C, покрокове налагодження через ST-Link.
Контрольна точкаВи можете пояснити, що робить analogWrite() «під капотом»: налаштовує таймер і регістр порівняння, як у CubeMX.

Як вчитися з ШІ, а не замість себе

  1. Спершу сформулюйте рішення словами, а потім просіть код.
  2. Просіть: «поясни кожен рядок як для C#-розробника».
  3. Після уроку: «постав мені 5 контрольних питань і перевір відповіді».
  4. Ламайте навмисно: приберіть pull-up, поставте delay(1000) у loop() і подивіться, що станеться.
  5. Ведіть нотатки «що я зрозумів» — так ви побачите прогалини.
