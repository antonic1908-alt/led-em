# 03. Програмне забезпечення (Windows)

## Мінімальний набір
| Програма | Навіщо | Де взяти |
|---|---|---|
| **VS Code** | редактор | https://code.visualstudio.com |
| **PlatformIO IDE** (розширення VS Code) | збірка, прошивка, бібліотеки, Serial Monitor; сам завантажує компілятори | вкладка Extensions → «PlatformIO IDE» |
| **Git for Windows** | історія змін, відкат помилок ШІ | https://git-scm.com |
| **Wokwi for VS Code** (розширення) | симуляція прямо з VS Code | Extensions → «Wokwi Simulator». Для приватних проєктів після пробного періоду потрібна платна ліцензія; онлайн wokwi.com безкоштовний для особистого використання |
| **ШІ-агент** | Claude Code / Copilot / інший | див. [02](02_ai_tools_vibecoding.md) |

## Для STM32 додатково
| Програма | Навіщо |
|---|---|
| **STM32CubeIDE** | офіційна IDE ST (Eclipse): HAL, налагодження |
| **STM32CubeMX** | графічне налаштування пінів і тактування (вбудований у CubeIDE, є й окремо) |
| **STM32CubeProgrammer** | прошивка через USB DFU або ST-Link |
| **Драйвер ST-Link** | для програматора ST-Link V2 (входить у CubeProgrammer) |

Усе завантажується з st.com (потрібна безкоштовна реєстрація).

## Необов'язково
- **Arduino IDE 2** — простіше за PlatformIO, підійде для перших 1–2 уроків.
- **ESP-IDF** — «рідний» фреймворк Espressif. Варто спробувати після проєкту.
- **PulseView** (sigrok) — якщо купите логічний аналізатор: щоб бачити сигнали I2C та ШІМ.

## Покрокове встановлення
1. Встановити VS Code → відкрити Extensions (Ctrl+Shift+X) → встановити **PlatformIO IDE** → перезапустити. Перший запуск триває кілька хвилин, бо PlatformIO завантажує Python і інструменти.
2. Встановити Git.
3. Відкрити папку `firmware/` (File → Open Folder). PlatformIO сам знайде `platformio.ini` і завантажить платформу та бібліотеки.
4. Внизу на синій панелі: ✓ — збірка, → — прошивка, 🔌 — Serial Monitor. Env (esp32c3 / blackpill) обирається там само.
5. Щоб `pio` працював з терміналу для ШІ-агента, додайте до PATH `%USERPROFILE%\.platformio\penv\Scripts`, або запускайте його з терміналу PlatformIO (іконка «PlatformIO Core CLI»).

## Особливості ESP32-C3 Super Mini
- USB підключений напряму до чипа (USB-Serial/JTAG), окремого чипа CH340 немає. Драйвер на Windows 10/11 зазвичай не потрібен.
- Щоб `Serial.println` виводив у USB, у `platformio.ini` має бути `-DARDUINO_USB_CDC_ON_BOOT=1` (вже є).
- **Якщо плата не прошивається або не з'являється COM-порт:** затисніть **BOOT**, натисніть і відпустіть **RESET**, відпустіть BOOT. Плата перейде в режим завантажувача, після чого прошивайте ще раз.
- Після прошивки в цьому режимі натисніть RESET.
- Використовуйте **USB-кабель з лініями даних**: дешеві кабелі «тільки для зарядки» не працюють.

## Особливості STM32F411 Black Pill
- **Без програматора (USB DFU):** затисніть **BOOT0**, натисніть **NRST**, відпустіть BOOT0. Плата з'явиться як «STM32 BOOTLOADER». Якщо не виходить з першого разу, тримайте BOOT0 довше.
- **З ST-Link V2:** підключіть SWDIO, SWCLK, GND, 3.3V. Так з'являється покрокове налагодження — дуже рекомендовано.
- **Платформа ESP32 у PlatformIO.** Використовуємо офіційну `platformio/espressif32`. Станом на листопад 2026 вона постачає Arduino-ESP32 3.3.x і не потребує Git. Спільнотна збірка **pioarduino** (новіший Arduino-ESP32) лишається закоментованою альтернативою в `platformio.ini`. Код сумісний з обома.

## Якщо збірка падає на Windows
| Повідомлення | Причина | Що робити |
|---|---|---|
| `Git not found in PATH` | платформі pioarduino потрібен Git | встановити Git або повернутися на `platformio/espressif32` |
| `FileNotFoundError … pkg-installing-…` під час розпакування | шлях довший за 260 символів (обмеження Windows) | увімкнути довгі шляхи в Windows (потрібні права адміністратора) або задати короткий каталог PlatformIO: змінна середовища `PLATFORMIO_CORE_DIR=D:\pio` |
| `An Application Control policy has blocked this file` | Smart App Control / політика Windows блокує невідомий файл з `.platformio` | повторити збірку (часто це разова перевірка репутації). Якщо блокується постійно, не вимикайте захист навмання — використовуйте офіційну платформу або зверніться до адміністратора |

## Перевірка, що все працює
```
cd lessons
pio run -e l01_blink -t upload
pio device monitor -b 115200
```
Вбудований LED (GPIO8) мигає, у моніторі щосекунди з'являється рядок `[blink] ...`.
