# 01. План навчання

**Для кого:** junior C#/Unity, електроніка на рівні школи або 1-го курсу.
**Тривалість:** ~6–8 тижнів по 5–8 годин на тиждень.
**Результат:** робоча розумна LED-стрічка на ESP32-C3, а потім той самий проєкт на STM32F411.

## Головна ідея
Мікроконтролер — це маленький комп'ютер без ОС, який виконує одну програму вічно.
Знання з Unity тут знадобляться напряму:

| Unity / C# | Мікроконтролер / C++ |
|---|---|
| `Start()` | `setup()` — виконується один раз після ввімкнення |
| `Update()` | `loop()` — крутиться нескінченно, тисячі разів на секунду |
| `Time.time` | `millis()` — мілісекунди від старту |
| `Input.GetKeyDown()` | читання піна + антибрязкіт (debounce) |
| `Debug.Log()` | `Serial.println()` |
| ScriptableObject з налаштуваннями | структура `Settings` у flash-пам'яті (NVS/EEPROM) |
| Animator state machine | `enum State` + `switch` |
| Coroutine з `yield WaitForSeconds` | **не можна** `delay()` — порівнюємо `millis()` з таймстемпом |
| Garbage Collector | його немає; уникаємо `new` і `String` в циклі |

## Етапи

### Етап 0 — Підготовка (тиждень 1)
- Встановити VS Code + PlatformIO, Git, драйвери (див. [03](03_software_setup.md)).
- Пройти Blink у Wokwi в браузері, нічого не встановлюючи: https://wokwi.com
- Прошити Blink на реальну ESP32-C3. **Контрольна точка:** мигає вбудований світлодіод, у Serial Monitor видно текст.

### Етап 1 — C/C++ для C#-розробника (тиждень 1–2, паралельно з уроками)
- Типи фіксованої ширини: `uint8_t`, `int16_t`, `uint32_t` (замість `byte`, `short`, `uint`).
- `const`, `constexpr`, `#define`; `#include` і header/source (`.h` = «інтерфейс», `.cpp` = реалізація).
- Вказівники та посилання (`&`) — на рівні «передати об'єкт без копіювання».
- `struct`, `enum class`, класи без віртуальних методів, `static`.
- Переповнення `millis()` і чому працює `if (millis() - t0 >= interval)`.
- Неблокуючий код і скінченний автомат.
- **Ресурси:** learncpp.com (розділи 1–13), «C++ для C#-розробників» (будь-який конспект), а також ШІ-асистент з промптом «поясни як C#-розробнику».

### Етап 2 — Периферія: уроки 01–08 (тиждень 2–4)
| Урок | Тема | Що вивчаємо |
|---|---|---|
| 01 | Blink + Serial | GPIO вихід, `millis()` |
| 02 | Кнопки | `INPUT_PULLUP`, брязкіт контактів, коротке/довге натискання |
| 03 | ШІМ + MOSFET | ШІМ, LEDC, низьковольтний ключ AO3400, плавне вмикання |
| 04 | АЦП + фоторезистор | дільник напруги, `analogRead`, фільтр |
| 05 | PIR HC-SR501 | цифровий датчик, налаштування потенціометрами |
| 06 | I2C: сканер + BH1750 | шина I2C, адреси, бібліотеки |
| 07 | OLED SSD1306 | U8g2, буфер кадру, шрифти |
| 08 | Дистанція | VL53L0X (I2C) або HC-SR04 (імпульси) |

Кожен урок: спершу Wokwi → потім макетка → потім змінити щось самому (завдання «Зміни сам» на сторінці уроку).

### Етап 3 — Проєкт (тиждень 4–6)
- Прочитати ТЗ ([06](06_project_spec.md)), зібрати схему ([05](05_hardware_bom_wiring.md)).
- Прошивку розбито на модулі: кнопки, датчики, драйвер стрічки, контролер, меню, налаштування.
- Спершу запустити готову прошивку з `firmware/`, потім розібрати кожен модуль разом з ШІ, потім додати власну функцію (наприклад, «нічний режим» на 20 % яскравості).

### Етап 4 — STM32 (тиждень 6–8)
- Той самий проєкт через PlatformIO + STM32duino. Змінюються лише піни (див. [07](07_stm32_port.md)).
- Далі — STM32CubeIDE + CubeMX + HAL: тактування, таймер у режимі ШІМ, I2C через HAL, налагодження через ST-Link (покрокове виконання, breakpoints).
- **Контрольна точка:** зрозуміти, що `analogWrite()` в Arduino «під капотом» налаштовує таймер так само, як ви робите це в CubeMX.

## Як вчитися з ШІ, а не замість себе
1. Спочатку спробуйте сформулювати рішення словами, потім просіть код.
2. Просіть «поясни кожен рядок як для C#-розробника».
3. Після кожного уроку попросіть ШІ поставити 5 контрольних питань.
4. Ламайте навмисно: приберіть pull-up, поставте `delay(1000)` у `loop()` — і подивіться, що станеться.
