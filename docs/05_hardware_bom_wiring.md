## Розрахунок живлення
- Знайдіть у характеристиках стрічки потужність на метр, **P (Вт/м)**. Струм на метр: **I = P / 5 В**.
  - SMD2835, 60 LED/м: ≈ 4.8–6 Вт/м → ≈ 1–1.2 А/м.
  - SMD5050, 60 LED/м (5V): ≈ 10–14 Вт/м → ≈ 2–3 А/м.
- **Блок живлення:** I_БЖ ≥ I_стрічки × 1.3 + 0.3 А (електроніка).
- **AO3400:** при 3.3 В на затворі комфортно до **~2 А** безперервно. Втрати: P = I² × Rds = 2² × 0.05 = 0.2 Вт, ледь тепло. При 3 А транзистор помітно гріється, тож потрібна площа міді на платі.
  - Для довших стрічок (> 2 А) візьміть потужніший logic-level MOSFET у корпусі TO-220 (наприклад, IRLB8721) або кілька AO3400 паралельно.
- **Стрічки 5V довше ~2–3 м** просідають за напругою (кінець жовтіє або тьмяніє). Подавайте живлення з обох кінців.

## Схема підключення (ESP32-C3 Super Mini)

```
 БЖ 5V (+) ──┬───────────────┬──────────────┬────────────────────┐
             │               │              │                    │
         [C 1000µF]     стрічка (+)    HC-SR501 VCC        (діод Шотткі)──► ESP32 5V
             │               │                                (якщо працюєте без USB)
 БЖ GND ─────┴──────┐   стрічка (−)
                    │        │
                    │      Drain
                    │    ┌─AO3400─┐
                    │  Gate     Source
                    │    │         │
     GPIO10 ──[100Ω]─────┤         │
                         [100k]    │
                         │         │
 СПІЛЬНА GND ════════════╧═════════╧════ ESP32 GND, усі датчики GND

 ESP32 3V3 ──► BH1750 VCC, OLED VCC, VL53L0X VIN, верх дільника LDR (10k)
 GPIO6 (SDA) ──► SDA усіх I2C-модулів (BH1750, OLED, VL53L0X)
 GPIO7 (SCL) ──► SCL усіх I2C-модулів
 GPIO3 ◄── HC-SR501 OUT
 GPIO0 ◄── середня точка дільника: 3V3 ─[10k]─┬─[LDR]─ GND  (або TEMT6000 SIG)
 GPIO4 ◄── кнопка UP     ─► GND
 GPIO5 ◄── кнопка DOWN   ─► GND
 GPIO1 ◄── кнопка OK     ─► GND
 GPIO8 ◄── кнопка MANUAL ─► GND   (при натисканні засвічується вбудований LED — це нормально)
 [опційно HC-SR04P] GPIO2 ─► TRIG, GPIO20 ◄── ECHO
```

### Таблиця пінів
| Сигнал | ESP32-C3 Super Mini | STM32F411 Black Pill |
|---|---|---|
| I2C SDA | GPIO6 | PB7 |
| I2C SCL | GPIO7 | PB6 |
| ШІМ → затвор AO3400 | GPIO10 | PA8 |
| PIR OUT | GPIO3 | PB0 |
| Аналоговий датчик світла | GPIO0 | PA1 |
| Кнопка UP | GPIO4 | PB12 |
| Кнопка DOWN | GPIO5 | PB13 |
| Кнопка OK | GPIO1 | PB14 |
| Кнопка MANUAL | GPIO8 | PB15 |
| HC-SR04 TRIG (опц.) | GPIO2 | PB8 |
| HC-SR04 ECHO (опц.) | GPIO20 | PB9 |

**Чому саме ці піни на ESP32-C3:**
- GPIO0–4 — єдині виводи з АЦП (ADC1), тому аналоговий датчик стоїть на GPIO0.
- GPIO8/9 за замовчуванням використовуються під I2C у багатьох прикладах, але це strapping-піни (а GPIO8 ще й LED), тому I2C винесено на вільні GPIO6/7.
- Кнопка на GPIO8 безпечна: вона замикає на GND лише при натисканні, а під час старту ніхто її не тримає.
- GPIO20/21 — це UART0. Під час старту на GPIO21 виходить лог завантажувача, тому його не використовуємо.

> Перевірте підписи на своїй платі. У деяких клонах Super Mini (наприклад, «Plus v2») LED і розводка відрізняються.

## Безпека — прочитайте перед першим ввімкненням
1. **Спільна земля** обов'язкова: GND БЖ, GND ESP32 і всіх модулів з'єднані разом.
2. **Не подавайте 5V від БЖ на пін 5V плати, коли підключено USB**, якщо немає діода Шотткі. Інакше два джерела живлення «боротимуться».
3. **Резистор 100k від затвора на GND** гарантує, що стрічка не ввімкнеться сама під час старту, поки пін ще «висить».
4. **Полярність:** стрічка, електролітичний конденсатор, БЖ. Спершу перевірте мультиметром.
5. **Нічого 5-вольтового на GPIO ESP32-C3.** HC-SR501 OUT — 3.3V, це нормально; звичайний HC-SR04 ECHO — 5V, тож лише через дільник.

## Чек-лист перевірки заліза
- [ ] Мультиметр: на 3V3 — 3.3V, на лінії 5V — 4.9–5.2V.
- [ ] Урок 06 (I2C-сканер) знаходить **0x23** (BH1750), **0x3C** (OLED), **0x29** (VL53L0X).
- [ ] Урок 03: стрічка плавно змінює яскравість, AO3400 після 5 хв на 100 % лише теплий.
- [ ] Урок 05: у Serial при русі `motion=1`.
- [ ] Фінальна прошивка: налаштування зберігаються після вимкнення живлення.
