# 06. ТЗ і архітектура проєкту «Розумна LED-стрічка»

## Що має вміти пристрій
1. Керувати одноколірною LED-стрічкою 5V через MOSFET AO3400 з плавною зміною яскравості (ШІМ 20 кГц, гамма-корекція).
2. **Режим АВТО:** вмикати стрічку, коли спрацьовує датчик руху та/або дистанції і **темно** (або завжди, якщо так налаштовано). Після останнього спрацювання тримати світло N секунд, потім плавно гасити.
3. **Режим РУЧНИЙ:** датчики ігноруються, стрічка вмикається та вимикається лише кнопкою.
4. Показувати стан на OLED і змінювати всі параметри меню кнопками UP / DOWN / OK.
5. Зберігати налаштування в енергонезалежній пам'яті (ESP32: NVS/Preferences, STM32: EEPROM-емуляція у flash).
6. Писати лог у Serial раз на секунду.

## Кнопки
| Кнопка | Головний екран | Меню (перегляд) | Меню (редагування) |
|---|---|---|---|
| **MANUAL** коротко | у РУЧНОМУ: увімк/вимк стрічку; в АВТО: перейти в РУЧНИЙ і перемкнути | вийти з меню (зі збереженням) | скасувати редагування |
| **MANUAL** довго (0.7 с) | перемкнути АВТО ↔ РУЧНИЙ | — | — |
| **OK** | відкрити меню | редагувати пункт / виконати дію | підтвердити значення |
| **UP / DOWN** | змінити яскравість ±5 % | рух по пунктах | змінити значення; утримання — автоповтор |

Меню закривається саме через 30 с без натискань, налаштування при цьому зберігаються.

## Параметри меню (значення за замовчуванням)
| Пункт | Діапазон | За замовч. | Сенс |
|---|---|---|---|
| Поріг світла, lx | 1–2000 | 30 | «темно», якщо освітленість нижча |
| Гістерезис, lx | 0–200 | 10 | «світло» настає лише вище поріг + гістерезис — щоб не блимало на межі |
| Датчик світла | BH1750 / Аналог | BH1750 | аналоговий — фоторезистор або TEMT6000 |
| Умова світла | Лише темно / Завжди | Лише темно | «Завжди» — ігнорувати освітленість |
| Тригер | Рух / Дист. / Рух АБО Дист. / Рух І Дист. | Рух АБО Дист. | що вважається «є людина» |
| Фільтр руху, мс | 0–2000 | 0 | **програмна чутливість PIR**: сигнал має триматися стільки мс, щоб зарахуватися (відсікає хибні спрацювання) |
| Утримання, с | 5–600 | 30 | скільки світити після останнього руху |
| Поріг дист., см | 5–400 | 80 | «близько», якщо ближче |
| Яскравість, % | 5–100 | 80 | цільова яскравість |
| Плавність, мс | 0–5000 | 800 | час повного вмикання і вимикання |
| Скинути налашт. | дія | — | повернути значення за замовчуванням |
| Вихід | дія | — | зберегти і вийти |

Апаратна чутливість PIR (дальність) регулюється потенціометром **Sx** на самому HC-SR501. Потенціометр часу **Tx** викрутіть на мінімум, а перемичку поставте в **H**, щоб час утримання задавала прошивка.

## Логіка режиму АВТО

```
                 тригер && (темно || «Завжди»)
      ┌─────┐ ───────────────────────────────► ┌────┐
      │ OFF │                                  │ ON │◄────┐
      └─────┘ ◄──── минув час утримання ─┐     └────┘     │ тригер знову
          ▲                              │       │ тригер зник
          │                           ┌──────┐   │
          └───────────────────────────┤ HOLD │◄──┘
                                      └──────┘───────────┘
```
- **Тригер:** обчислюється з руху (з урахуванням фільтра) і дистанції (`dist < поріг`) відповідно до пункту «Тригер».
- **«Темно» з гістерезисом:** `lux < поріг` → темно; `lux > поріг + гіст.` → світло; між ними — без змін.
- **Важливо:** «темно» оцінюється **лише коли стрічка вимкнена (OFF)**. Інакше світло самої стрічки потрапить на датчик, і вона вимкне сама себе — класична помилка зворотного зв'язку.
- Яскравість змінюється плавно: `LedDriver` веде поточний рівень до цільового зі швидкістю 100 % / «Плавність».

## Архітектура прошивки (`firmware/src/`)
| Файл | Відповідальність | Аналог в Unity |
|---|---|---|
| `config.h` | піни для ESP32/STM32, константи, режим симуляції | конфіг-константи |
| `Settings.h/.cpp` | структура налаштувань, межі, збереження у flash | ScriptableObject + PlayerPrefs |
| `Buttons.h/.cpp` | антибрязкіт, події Short / Long / Repeat | Input System actions |
| `Sensors.h/.cpp` | `LightSensor`, `MotionSensor`, `DistanceSensor` | компоненти-сенсори |
| `LedDriver.h/.cpp` | ШІМ, гамма, плавний fade | твін (DOTween) |
| `Controller.h/.cpp` | режими й state machine | Animator / GameManager |
| `Ui.h/.cpp` | екрани й меню на OLED (U8g2, кирилиця) | UI Canvas |
| `main.cpp` | `setup()` / `loop()`, з'єднує все разом | сцена + bootstrap |

**Принципи:**
- **Жодного `delay()`.** Кожен модуль має `update(now)`, який повертається за мікросекунди — як `Update()` у Unity.
- Модулі не знають один про одного; зв'язує їх `main.cpp`.
- Апаратні відмінності ESP32 і STM32 сховані за `#if defined(ARDUINO_ARCH_ESP32)` у трьох місцях: піни, ШІМ, збереження.

## Формат логу
```
[main] ready, light=BH1750 dist=VL53L0X
[ctrl] mode=AUTO state=HOLD(12s) lux=8.4 dark=1 motion=0 dist=54cm near=1 out=80%
```

## Критерії приймання
- [ ] Темно + рух → стрічка плавно вмикається за «Плавність» мс.
- [ ] Рух зник → через «Утримання» с плавно гасне. Новий рух під час утримання продовжує світіння.
- [ ] Світло в кімнаті (lux > поріг + гіст.) → рух не вмикає стрічку (у режимі «Лише темно»).
- [ ] Стрічка, що світить на датчик, не вимикає сама себе.
- [ ] Довге MANUAL перемикає режим; у РУЧНОМУ коротке MANUAL вмикає/вимикає стрічку, датчики ігноруються.
- [ ] Усі пункти меню змінюються, зберігаються, переживають перезавантаження.
- [ ] Без BH1750 прошивка автоматично переходить на аналоговий датчик. Без датчика дистанції показує «--» і не падає.
